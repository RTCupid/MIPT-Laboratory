\chapter*{Аннотация}
\addcontentsline{toc}{chapter}{Аннотация}

Методом изобарического расширения найден показатель адиабаты  углекислого газа $\gamma = 1.293 \pm 0.018$. Это значение совпало в пределах погрешности с табличным $\gamma_\text{табл} = 1.310$. Совпадение значения с табличным показало, что данный метод позволяет определить показатель адиабаты с погрешностью 1.5\%.
