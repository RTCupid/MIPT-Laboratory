## Описание

Папка для каждой работы содержит PDF-файл с отчётом (lab_#_#_#.pdf), программы на языке LaTex для каждого раздела работы и подпапку "img" с изображениями, используемыми в отчёте. Графики для работ строились при помощи программ на языке Python. В работе 2.3.1 для построения графиков использовался Gnuplot, встроенный в LaTex редактор Overleaf. Для создания графиков при помощи Gnuplot в работе 2.3.1 присутствует подпапка txt с экспериментальными данными в текстовом формате.
